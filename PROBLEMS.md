# Проблемы и ограничения проекта Ватага

## Статус: Нет блокеров

Все модули реализованы, сборка проходит без ошибок, dev-сервер и preview-сервер отвечают.

## Известные ограничения

### 1. TURN-сервер Cloudflare — публичные креденшлы
- **Проблема**: Используются бесплатные публичные креденшлы `free:free`
- **Влияние**: Могут быть rate-limited при большом количестве подключений
- **Решение**: Зарегистрироваться в Cloudflare Calls для получения собственных креденшлов

### 2. PeerJS public cloud — rate limits
- **Проблема**: Публичный PeerJS сервер имеет лимиты
- **Влияние**: При частых переподключениях может блокировать
- **Решение**: Развернуть свой PeerJS сервер (`npm i peer`)

### 3. Mesh-топология — ограничение масштаба
- **Проблема**: Каждый участник отправляет поток всем остальным
- **Влияние**: 8 человек = 7 исходящих потоков. На слабых устройствах возможны лаги
- **Решение**: Для 8+ человек нужен SFU (mediasoup, Janus)

### 4. Передача файлов — ограничение памяти
- **Проблема**: Файлы собираются в Blob в памяти
- **Влияние**: Файлы 10+ ГБ могут вызвать нехватку памяти
- **Решение**: Стриминговая запись в OPFS (Origin Private File System) или File System Access API

### 5. Симметричный NAT
- **Проблема**: Некоторые корпоративные сети блокируют P2P
- **Влияние**: Соединение не установится
- **Решение**: Требуется прокси-сервер (coturn) или SFU

### 6. HTTPS обязателен для getDisplayMedia
- **Проблема**: Демонстрация экрана работает только на HTTPS или localhost
- **Влияние**: Без HTTPS скриншар не работает
- **Решение**: Использовать HTTPS (Cloudflare Pages/Vercel дают автоматически)

### 7. Нет авторизации комнат
- **Проблема**: Любой с кодом может войти
- **Влияние**: Нет защиты от непрошеных гостей
- **Решение**: Добавить пароль комнаты (не реализовано в MVP)
